Quick Start

  1. Clone the repo and copy .env.example → backend/.env
  2. Set your VESTING_CONTRACT_ID, TOKEN_CONTRACT_ID, MULTISIG_CONTRACT_ID
  3. Run make build to compile the contracts
  4. Run make deploy-testnet to deploy
  5. Start the backend: cd backend && npm install && npm start
  6. Open this dashboard and start interacting!
